¿Qué es Git?

Git es un sistema de control de versiones que permite registrar los cambios realizados en un proyecto, recuperar versiones anteriores y trabajar en equipo.

¿Qué es GitHub?

GitHub es una plataforma online que permite almacenar repositorios Git, compartir código y colaborar con otros desarrolladores.

Comandos básicos de Git

1. Configurar usuario

Configura tu nombre de usuario:

git config --global user.name "Tu Nombre"

2. Iniciar un repositorio

Inicializa Git en tu proyecto:

git init

3. Agregar archivos

Agrega los archivos al área de preparación:

git add .

4. Guardar cambios

Crea un commit con tus cambios:

git commit -m "Primer commit"

5. Ver el estado

Consulta los cambios del proyecto:

git status

6. Subir cambios

Envía los cambios a GitHub:

git push origin main

7. Descargar proyecto

Clona un repositorio:

git clone URL_DEL_REPOSITORIO
